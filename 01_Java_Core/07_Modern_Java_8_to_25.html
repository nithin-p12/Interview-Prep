1. The big picture

1.1

The LTS timeline

click a version — small dots are the 6-monthly releases in between

Remember: since Java 10 a new version ships every 6 months (March and September). Companies run LTS versions: 8, 11, 17, 21, 25 — now one every 2 years. Features usually arrive as preview first and become final a few releases later.

Good to know
"Java 21 feature" in an interview usually means final in 21. A preview feature needs --enable-preview and may still change — don't ship it to production.

2.2

Records

immutable data carriers — can a record…?

Remember: a record is final, its fields are final, accessors have no get prefix. Validate in the compact constructor. Immutability is shallow — copy mutable lists.

extend another class?
Records implicitly extend java.lang.Record and are final.
implement an interface?
Yes — e.g. record Passed(long ms) implements Outcome.
declare an extra
instance field?
Only the components are instance fields. Static fields and methods are allowed.
be a JPA @Entity?
No — JPA needs a no-arg constructor, mutable state and proxies. Use records for DTOs and query projections.
be a Spring request /
response DTO?
Yes — Jackson (2.12+) maps records, and @Valid works on components.
override toString()
or an accessor?
Yes, you can override generated methods — e.g. mask a token in toString().
