How this folder is organised

  • One folder per subject, numbered in study order: 01_Java_Core, 02_Design_Patterns, 03_System_Design …
  • Inside a folder, files are numbered too: 01_…html, 02_…html. The HTML page is the main version.
  • Poster / image versions live in that folder's images/ subfolder with the same number.
  • Superseded versions go to _archive/ instead of being deleted.
  • New pages are added to this index. Progress: PROGRESS.txt · output rules for any agent: AGENT_INSTRUCTIONS.txt.
